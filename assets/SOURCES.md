# Fuentes de recursos

## Mapa de Bolívar

`partido-bolivar.svg`: contornos derivados de la capa Departamento del Instituto Geográfico Nacional, consultada el 16 de octubre de 2026. Bolívar: código INDEC 06105. Proyección local equirectangular con ajuste de longitud a 36,3° S; presentación ilustrativa, no para uso catastral. No se simplificó el contorno principal (810 coordenadas); los vecinos usan tolerancia de 0,001°.

Servicio: https://ide.ign.gob.ar/geoservicios/rest/services/ANIDA/basicas/MapServer/4
